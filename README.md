# ЭСЛАВИЯ — Telegram Mini App (каталог)

Static Telegram Mini App with the Eslavia wholesale catalog (98 models).
Served by GitHub Pages: https://paulos99.github.io/eslavia-app/

- `index.html`, `styles.css`, `app.js` — the app (no framework, no build step)
- `data/catalog.json` — generated by `scripts/build_data.py` from the site data
  (`eslavia-site/data/products.json`) and the channel state (`eslavia-tg/state.json`)
- `img/<id>/` — light WebP images: `01-480` for the grid, `01/02/03-720` for the gallery
  (the same 3 photos as the channel album)
- `brand/cover-640x360.png` — cover for @BotFather `/newapp`

Rebuild after catalog changes: `python3 scripts/build_data.py`, then commit and push.

Deep links: `?startapp=<model id>` (e.g. `m-102`) opens a model, `?startapp=cat-<index>` opens a category.
